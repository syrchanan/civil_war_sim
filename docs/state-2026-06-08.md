## Completed Features

### Unit layer (stable)
- `Regiment`, `InfantryRegiment`, `CavalryRegiment`, `ArtilleryBattery`, `Army` — all implemented with `from_dict` deserialization and subtype validation against `config/unit_subtypes.yaml`
- `Position` class with flat/true/elevation distance methods; distance methods also on `Regiment`
- All morale/config values read from `get_config()` — nothing hardcoded in logic files

### Config system
- `config/` holds 8 YAML files: `combat.yaml`, `morale.yaml`, `map.yaml`, `cover.yaml`, `weather.yaml`, `movement.yaml`, `visualization.yaml`, `unit_subtypes.yaml`
- `ConfigLoader` singleton merges all `.yaml` files in the directory — API unchanged from a single-file perspective

### Map pipeline (`imperial_generals/map/`)
| File | Responsibility |
|---|---|
| `Cell.py` | Cell dataclass (index, center, polygon, elevation, terrain_type, cover_value) |
| `elevation.py` | `ElevationConfig`, `TerrainPresets` (6 presets incl. cliff), `ElevationGenerator` |
| `biome.py` | `TerrainZone`, `BiomeMapConfig`, `BiomePresets` (4 presets + cliffs_and_valleys), `BiomeGenerator` |
| `voronoi.py` | `PoissonDiscSampler`, `VoronoiMap` |
| `generator.py` | `MapConfig`, `MapResult`, `MapGenerator` (pipeline orchestrator) |
| `river.py` | `RiverGenerator` — Stage 3, greedy downhill walk + BFS escape |
| `viewer.py` | `MapViewer` — three togglable views (elevation, terrain_type, cover_value) |

**Pipeline stages wired up:**
- Stage 1 — Voronoi mesh (Poisson disc → diagram → clipped cells)
- Stage 2 — Biome assignment OR elevation-only
- Stage 3 — River generation (`RiverGenerator`: source→sink greedy walk, STRtree neighbour graph, BFS fallback)
- Stages 4–6 — Stubs only (`num_lakes`, `num_roads` on `MapConfig`; not yet executed)

**Map API entry points:**
```python
MapGenerator.from_config(preset='mixed_battlefield')          # reads config defaults
MapGenerator.from_preset('mixed_battlefield', seed=42, ...)   # explicit dims
MapGenerator(MapConfig(...)).generate_map()                    # full custom config
```

### Visualization
`MapViewer` renders three views toggled with ←/→ keys. Terrain colours read from `visualization.yaml`. Feature layer overlay (rivers/lakes/roads/fences drawn on top) is deferred until those features are generated.

## Key Design Rules (as established)

- **TDD**: write failing test first, then implement. Never the other way.
- **Python-first**: no TypeScript work until Python is stable and fully tested.
- **No hardcoded constants**: everything comes from `get_config()` with `field(default_factory=lambda: get_config()[...])` on dataclasses.
- **`# pragma: no cover`** on `__main__` blocks and unreachable defensive branches only.
- **`conftest.py`** forces `matplotlib Agg` backend — never import pyplot without this in tests.
- **100% coverage** is a hard requirement; do not merge a feature that breaks it.
